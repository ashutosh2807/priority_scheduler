State guide

A transparent handoff from schedule definition to outcome.

Open report-date calendar
1
Schedule MasterFrequency, margin, holiday rule, confirmation flag, and time window define the business rule.
2
STAGINGThe scheduler preserves occurrence/report dates and checks DATEMAST, date, time, control, and confirmation gates.
3
READY priority orderOnly fully eligible occurrences persist here and receive a priority key.
4
Execution historyThe worker records running, success, failure, retries, and report date.

Manual run and confirmation only record control intent. The scheduler still evaluates the occurrence and manages its queue position; the browser never runs Oracle directly.
